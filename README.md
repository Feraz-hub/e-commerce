# Sneaker Product Page

An interactive e-commerce product page built with HTML, CSS and vanilla JavaScript. This frontend project focuses on browsing product images, choosing a quantity and managing a cart preview.

## Interface and interactions

- Product information, pricing and image thumbnails.
- Desktop image preview and a mobile image slider.
- Quantity controls and add-to-cart interactions.
- Cart preview and mobile navigation overlay.

## Stack

HTML · CSS · JavaScript · DOM events

## Run locally

No package installation or build step is required. With Python 3 installed:

```bash
git clone https://github.com/Feraz-hub/e-commerce.git
cd e-commerce
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). On Windows, use `py -m http.server 8000` if `python` is not available.

## Project map

| Path | Purpose |
| --- | --- |
| `index.html` | Product page and cart markup |
| `js/main.js` | Gallery, navigation and cart interactions |
| `css/` | Page styles and icon styles |
| `images/` | Product photography and interface graphics |
| `design/` | Design references |

## Scope

This is a frontend demonstration. Checkout is an interface element; there is no payment processing, inventory service or order backend. Keyboard access, focus management and cart edge cases are useful next improvements.
